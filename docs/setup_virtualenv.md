# Entorno virtual local

El entorno virtual vive en `venv_antigenlm/` y no se debe versionar.

## macOS / Linux

```bash
python -m venv venv_antigenlm
source venv_antigenlm/bin/activate
pip install -r requirements.txt
```

## Windows PowerShell

```powershell
python -m venv venv_antigenlm
.\venv_antigenlm\Scripts\Activate.ps1
pip install -r requirements.txt
```
